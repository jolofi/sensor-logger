# Environmental Sensor Data Logger

This repository contains an automated Python script developed to parse and filter high volume raw temperature and humidity datasets. 

### Data Parsing and Efficiency
* Engineered automated filtering logic to process the raw dataset.
* Decreased manual data sorting time by over 80 percent through algorithmic parsing.

### Visualization and Diagnostics
* Engineered real time visual plots of sensor measurements utilizing MATLAB and the Python Matplotlib library.
* Created diagnostic tools to successfully identify simulated sensor calibration errors within the dataset.
